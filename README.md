# SMC-WildFire

**Work in Progress**

Python implementation of Sequential Monte Carlo methods for wildfire propagation tracking and data assimilation, including particle filtering and diffusion-based ensemble filtering (EnSF).

**Reference paper :** [Fire-EnSF: Wildfire Spread Data Assimilation using Ensemble Score Filter](https://arxiv.org/abs/2510.15954).

This project is part of the Hidden Markov Models and Sequential Monte Carlo course at ENSAE Paris (third year).

Implementation and experiments are currently in progress.
